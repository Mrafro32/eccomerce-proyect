# Gestión de Carritos de Compra, Sesiones y Ranking en Tiempo Real con Redis Cloud

Aplicación backend desarrollada en Node.js y Express conectada a una instancia administrada de **Redis en la nube** (Upstash / Redis Cloud), implementando el paradigma NoSQL **Clave-Valor**.

## Requisitos Previos
- Node.js v18+ instalado.
- Cuenta gratuita en [Upstash](https://upstash.com/) o [Redis Cloud](https://redis.com/try-free/) con una base de datos creada.
